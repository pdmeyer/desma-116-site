Use Ocen Audio to edit your field recordings

Trim the recordings to length, edit out any unwanted items (handling noise,
etc), export them to WAV files. Using the waveform and spectograph views to
find areas with unwanted artifacts.

Use the Universal Category System file name convention
<https://universalcategorysystem.com/>

For each field recording team:

- Combine your sounds and create a 1 - 3 minute "sizzle reel". Pick your favorite ~10 sounds and include them sequentially in the sizzle reel file. The point is for me to be able to hear the sounds you created/discovered.
- a 1-minute "sizzle reel" that has all of your sounds one after the other (so that it is easy for me to listen to them!!)

Here is an example sizzle you can use for reference: <https://drive.google.com/file/d/12CcpLVXjlrY3szw52lSLDfe73yIqhsuV/view?usp=drive_link>

## Creating the Sizzle Reel

First, create a new file in Ocen Audio by clicking the `+` at the top of the file browser:

![ocen-create-file](img/ocen-create-file.jpg)

Use these settings:

![ocen-create-file-settings](img/ocen-create-file-settings.jpg)

You will now have a new blank file in your file browser. This will be your sizzle.

Go to one of your other files, select a region (1 - 10 seconds, depending on the sound) and copy it.

![ocen-copy-audio](img/ocen-copy-audio.jpg)

Then go back to your currently empty sizzle file, and paste. Repeat this
process multiple times to add multiple files. Click to position the white
marker at the end of the file to paste to the end of the file.

![ocen-paste-audio](img/ocen-paste-audio.jpg)

Now is a good time to mark this section using either a region or a marker. Regions and markers can be created with `CMD + k` (Mac) or `CTRL + k` (windows). If you have an area of the file selected, it will create region. Otherwise, it will create a marker.

![ocen-region](img/ocen-region.jpg)

Either a region or a marker is fine, it doesn't really matter. They're convenient because they mark the boundaries of your individual sounds, which will make adjusting the volume of each sound and adding fade ins/ fade outs easier.

You can jump between markers using `CMD + OPT + left/right arrow` (Mac) `CTRL + ALT + left/right arrow` (Windows). If you hold `SHIFT` while jumping, you will select. This makes it easy to select the area between two markers.

When you have an area selected, you can change the volume using the hover controls that appear. Adjust the volume so that it's about the same as the other sections.

![ocen-gain-control](img/ocen-gain-control.jpg)

If you really want to make me happy, select a small area (~ 0.5 seconds) at the beginning and end.

![ocen-fade-in](img/ocen-fade-in.jpg)

Here's an example of what your audio should look like at the end:

![ocen-sizzle](img/ocen-sizzle.jpg)

Finally, export the file.

![ocen-export](img/ocen-export.jpg)
